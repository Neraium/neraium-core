# GROW DECISION MODEL

The Grow decision layer is deterministic and scope-aware.

- Structural drift comes from the reusable structural analytics engine plus grow-domain heuristics.
- Scope rollups aggregate plant, zone, room, subsystem, facility, and portfolio views from the same telemetry base.
- Inefficiency is scored in four buckets: energy, climate, process, and biological.
- Time-to-impact is heuristic, conservative, explicit, and advisory.
- Threshold contrast is always visible when applicable.
