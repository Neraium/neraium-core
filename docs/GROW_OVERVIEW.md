# GROW OVERVIEW

Neraium Grow is a read-only intelligence layer for cultivation facilities. It learns structural behavior from telemetry across climate, HVACD, irrigation, fertigation, lighting, CO2, airflow, power, and biological proxy signals, then surfaces drift, inefficiency, and likely impact before conventional alarms or yield outcomes deteriorate.

Grow is the default runtime in this repository. Markets remains available as a legacy module.
