# GROW COMPARE

Comparison routes:

- `GET /compare`
- `POST /compare/entities`

Supported comparisons:

- plant vs plant
- zone vs zone
- room vs room
- subsystem vs subsystem
- facility vs facility
- entity vs peer baseline
- entity vs best performer

Comparison output includes relative drift, relative inefficiency, ranking position, best-performer delta, peer-median delta, and likely causal differences.
